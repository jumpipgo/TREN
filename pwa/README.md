# МЕЗО PWA

Готовый вариант тренировочного приложения для установки на Android через браузер.

## Что внутри

- `index.html` — приложение;
- `manifest.webmanifest` — имя, иконки и standalone-режим;
- `service-worker.js` — офлайн-кэш оболочки приложения;
- `icons/` — иконки приложения.

## Как запустить

Из этой папки:

```bash
python -m http.server 8765 --bind 0.0.0.0
```

На компьютере открой:

```text
http://127.0.0.1:8765/
```

На телефоне в той же Wi-Fi-сети открой:

```text
http://IP-КОМПЬЮТЕРА:8765/
```

Например:

```text
http://192.168.1.50:8765/
```

## Установка на OnePlus 15

Для полноценной установки лучше использовать HTTPS-хостинг.

1. Открой сайт в Chrome на Android.
2. Нажми меню браузера.
3. Выбери `Установить приложение` или `Добавить на главный экран`.
4. Подтверди установку.
5. После установки МЕЗО запускается без адресной строки браузера.

Если кнопка установки не появляется, проверь, что сайт открыт по HTTPS, а не через `file://` или обычный HTTP.

## Важно

- Для загрузки видео с YouTube нужен интернет.
- Интерфейс и журнал тренировок работают из локального кэша после первого успешного открытия.
- Прогресс хранится в `localStorage` браузера/профиля PWA.
